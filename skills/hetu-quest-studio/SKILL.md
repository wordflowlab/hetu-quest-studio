# 游戏任务工坊

先发现当前已启用包、真实Schema和同包方法，携带确切WorkRef、management_ref及活动包／能力摘要。先读取固定作品、已有工程、来源、成果和意见，不重复创建或要求作者手填。

读取固定故事依据 → 任务阶段与有界变量 → 条件与选择代价 → 核对状态可达性 → 固定路线试玩 → 改条件后复核 → 任务本及固定轨迹。

变量为有界整数或0／1标记，条件与效果引用明确变量；重复效果、越界初值和悬空引用拒绝。转移先核验当前阶段和全部守卫，再原子应用效果；循环允许但试玩和状态搜索有界。路线固定变量、阶段和转移组合摘要，改条件后旧路线不能当当前试玩。试玩记录保存完整专业快照与程序计算的轨迹，旧记录不覆盖，不能提交伪造状态。状态搜索达到预算返回无法判断，不把未搜到当不可达。

互动叙事拥有分支文本、存档和故事试玩，本包专注任务条件、资源效果与状态可达性。游戏引擎拥有运行时资源、联网玩家和正式游戏发布；本包不提供战斗平衡认证、在线运营或任意脚本执行。

[流程与反例](references/workflows.md)提供专业方法；[操作地图](references/operations.md)从正式清单生成。每阶段保存后回读固定修订；未知先get_operation，CAS保留原输入。用create_handoff接续下一阶段，正文采纳、定稿、外发与费用分别按确切作者决定。
