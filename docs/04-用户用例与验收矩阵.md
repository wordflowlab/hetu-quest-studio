# 用户用例与验收矩阵

| 用例 | 正向 | 反向及边界 |
| --- | --- | --- |
| 01 状态 | 标记与计数有明确范围 | 初值、效果越界拒绝 |
| 02 转移 | 同一前态检查全部条件，原子应用效果 | 失败不部分扣资源 |
| 03 循环 | 合法循环保留，路线明确步数预算 | 不无限执行 |
| 04 可达性 | 枚举完整状态或明确预算不足 | 未搜到不直接判不可达 |
| 05 快照 | 固定路线和试玩完整状态轨迹 | 改图后旧记录不套新图 |
| 06 伪造 | 新记录轨迹由确定性模拟复算 | 整本保存也不能伪造结果 |
| 07 交付 | 任务本、状态图和固定JSON | 不执行游戏引擎脚本 |
| 09 固定作品 | 小说、独立剧本、独立视频各自获权和读取 | 错作品引用、撤权及错误摘要拒绝 |
| 10 操作恢复 | 同键重放、写后丢回执、旧修订回读 | 同键异参、未知结果不重复落盘 |
| 11 热插拔 | 同连接发现Skill，安装启停卸载重装 | 停用与旧活动绑定拒绝；历史保留 |
| 12 作者审核 | 五页、浅暗、1360／760、键盘及降级 | 空、错误、取消、CAS保留与关闭恢复 |
| 13 组合接续 | 四包固定专业依据接续并准备宿主候选 | 不合并管理权或修改原稿 |
| 14 公开交付 | 固定Tag、双摘要、重新下载安装与官网 | 不覆盖同版本附件或公开私密绑定 |

先执行领域正反例和真实应用单元，再正式制品CLI/MCP逐动作、包内Skill、实际Electron与当前Codex。例子采用原创虚构资料，不冒充真人研究、文献权利或专业判断认证；跨视口检查不等于Windows/Linux专业实机。
