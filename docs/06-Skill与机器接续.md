# Skill与机器接续

包内hetu-quest-studio由河图动态发现，不创建Codex插件、独立MCP服务器或客户端工具名。安装和启用后重新读取活动包摘要、capabilities与skills.read；旧能力绑定不得继续使用。业务无需启动桌面。

默认旅程：读取固定故事依据 → 任务阶段与有界变量 → 条件与选择代价 → 核对状态可达性 → 固定路线试玩 → 改条件后复核 → 任务本及固定轨迹。先读已有工程、固定作品及意见，不新建另一份演示工程替代接续。方法由Skill维护，确定性规则由专业后端执行。

变量为有界整数或0／1标记，条件与效果引用明确变量；重复效果、越界初值和悬空引用拒绝。转移先核验当前阶段和全部守卫，再原子应用效果；循环允许但试玩和状态搜索有界。路线固定变量、阶段和转移组合摘要，改条件后旧路线不能当当前试玩。试玩记录保存完整专业快照与程序计算的轨迹，旧记录不覆盖，不能提交伪造状态。状态搜索达到预算返回无法判断，不把未搜到当不可达。

每阶段保存并回读固定修订，create_handoff记录依据、目标与未解决问题。其他插件根据实际安装能力独立发现，通过固定专业引用组合。未知先回读，正文采纳、定稿、内容外发与费用按作者确切决定执行。

SKILL.md作为精炼方法入口，references/workflows.md提供专业方法与反例，operations.md从正式清单生成。专业清单由本仓库维护，宿主40只导航动态入口。
